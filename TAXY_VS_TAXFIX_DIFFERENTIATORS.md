# Taxy versus Taxfix: product differentiators

This comparison uses only Taxfix public product and support materials. It does not copy code,
assets, wording or visual design.

| Dimension | Public Taxfix pattern | Taxy opportunity |
|---|---|---|
| Guided input | Personalized questions instead of forms | Portuguese interview backed by `FiscalProfile` |
| Repeated input | Prior-year/prefilled data reduces re-entry | Profile, local ledgers and e-Fatura evidence prefill questions |
| Result | Estimated result plus calculation detail | Explicit ready/provisional/incomplete state and exact engine explanation |
| Returning user | Continue and reuse known data | Year-scoped annual companion with dirty-section review |
| Documents | Upload/capture supports the flow | Confirmation-first `DocumentInput` foundation |
| Next action | Guided completion/submission steps | Deterministic Portuguese next action without inventing obligations |

## Taxy differentiators

1. Real Portuguese e-Fatura read-only evidence through `api.taxy.pt`.
2. Portuguese fiscal profile and IRS engine with unsupported cases kept fail-closed.
3. An estimate that evolves across the year as confirmed data changes.
4. Local year-scoped interview and snapshots that remain useful offline.
5. A future path to accountant collaboration without exposing fiscal answers to analytics.

The largest current Taxfix-style gap remains broad document ingestion and complex-income
coverage. Taxy's strongest advantage is connecting a guided Portuguese experience to real
e-Fatura evidence while preserving `unavailable != zero`.

# Technical request to the Portuguese Tax Authority — read-only DM3IRS access

**Subject:** Request for technical information about a read-only DM3IRS integration

Dear Sir or Madam,

Taxy is a Portuguese application designed to help taxpayers organize tax information and obtain clearly labelled IRS estimates. We would like to assess an official, taxpayer-consented and strictly read-only integration with the DM3IRS service family. We are not requesting declaration submission or any other operation that changes data held by the Portuguese Tax Authority.

Could you please confirm whether DM3IRS is available to third-party integrators; whether an onboarding, contractual or homologation process exists; how client certificates are issued or allow-listed for mTLS; whether a quality environment and synthetic test data are available; which read-only operations may be authorized; and whether official WSDL/XSD, SOAPActions and versioning policies can be supplied?

We would also appreciate details on operation-level entitlements, rate limits, timeout/retry rules, taxpayer and representative authentication, consent requirements, data-protection/retention/audit obligations, production approval and the appropriate technical contact.

Our proposed first validation would use only the quality environment, start with a non-personal catalog read and execute no more than one request per approved step. Taxy can provide its security architecture, consent model, retention policy and controller/processor details for review.
